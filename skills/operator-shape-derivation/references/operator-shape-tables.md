# 算子 shape 表格交付

表格优先回答三个问题：调用哪个算子、每个参数的 shape 是什么、数值和公式从哪里来。交付全量清单时，保留用户指定范围内的算子和捕获分支，按证据标注缺口；用户只看主模型时，按主模型范围筛选。

## 表格形式

用户要求 CSV 时，提供可独立打开的 CSV。需要多页对照时，用一个 Excel 工作簿组织相同数据，同时可按页导出独立 CSV。面向 Windows Excel 的中文 CSV 使用 UTF-8 BOM，并用标准 CSV writer 保存带换行的单元格。沿用项目已有模板的页名和术语。

| 页签 | 一行表示 | 应优先看到的字段 |
| --- | --- | --- |
| 算子数值 | 一个捕获 case 或具体配置 case | 算子、调用分支、case_id、具名输入和输出 shape。已采集时附次数、原 CSV 行号及映射证据 |
| 算子符号 | 一个接口或 shape 关系一致的调用分支。需要逐例对照时可按 case 展开 | 具名输入公式、具名输出公式、简短的轴关系说明、同一分支的数值实例及 case_id |
| 逐张量数值 | 一个输入或输出槽位 | case_id、算子、方向、参数名、shape、dtype、format/layout、映射状态和证据。slot 与原始描述符保留为追溯字段 |
| 算子属性 | 一个接口属性。值域随分支或平台变化时按适用条件展开 | 属性名、类型、已核实的枚举或范围、默认值、本次生效值或源码分支、约束及来源 |
| 变量说明 | 一个符号与其作用域 | 含义、数值或范围、作用域和来源。链路或空槽排查较多时，可沿用项目已有的链路/空槽页 |

输入与输出分列，主视图每个参数独占一行，例如 `block_table [41,150]` 和 `cu_seqlens_q [42]`。同一 case 的数值页、符号页和逐张量页使用一致的参数名。长列表在工作簿中启用换行，并让行高覆盖参数列表；宽表可冻结表头和标识列。主要结论放在靠前列，raw slot 和完整来源可放在后列供查证。

## 参数、符号、属性及证据

- **参数边界**从真实接口、注册、binding 或适配器确定名称和顺序。profiling 压缩、重排、别名或合并同形参数时，给出映射证据、候选名或“待映射”。在接口明确后，按该分支列齐权重、bias、norm 参数、量化 scale、mask、索引、cache/state、metadata 和输出。可选项注明生效条件以及该次是否有形状记录。
- **权重和符号**把公式写在对应参数旁边，解释维度来自哪里，并代入一个同分支实例。例如在加载时补齐 Q 头的融合分支中，`MlaPrologV3.weight_uq_qr` 的逻辑 shape 为 `[q_rank,padded_q_heads*(nope_dim+rope_dim)]`。若压缩维度为 1536，补齐后有 128 个头，单头宽度为 128+64，则得到 `[1536,24576]`。其余投影权重、RMSNorm 权重、反量化 scale 同样逐项列出。描述符涉及 FP4 打包、NZ 或 backing buffer 时，标明展示的是逻辑 shape、打包 shape 或存储长度。符号未恢复时可保留具名实测实例。
- **分支**主模型和草稿、P/D、history/current、不同 dtype 或布局的 shape 不同时，分别列出。符号页的实例与对应调用一致。把共用符号的取值和作用域放到变量说明页，保持 token 数、请求数、head 数、缓存容量及有效行数各自独立。
- **属性**从当前代码、设备注册、接口文档或配置提取类型、枚举、范围和默认值。列出枚举值的含义和跨属性约束，并标明版本或后端适用范围。默认值与本次生效值各有来源。只有部分分支有证据时，记录已核实的值及其限制。
- **空 shape**保留 profiling 原样。可通过代码复核的情况注明标量 `[]`、空 Tensor（如 `[0]`）、分支下可选 `None` 或条件推导。其余空字段继续标记“未采集 shape”或“待确认”，并保留 dtype、slot 和原始值。

## 回读检查

- 按用户指定的范围核对算子、case、张量行数、调用次数合计和各页 case_id。确认数值和符号都覆盖接口权重及输出，属性行可追到源码或适用范围。
- 抽查一个多输入算子和一个含权重的分支，对照源码顺序、profiling 原始描述符、符号公式和代入结果。CSV 与 Excel 同时交付时回读核对关键列；必要时对全量单元格检查一致性。
