# 广播、配对、门控与量化的语义边界

名字相同的算子可能具有不同属性、布局或输出；先读当前冻结规格。以下是选择切分与复用的知识，不是新增 API 支持声明，也不提供固定切换阈值。

| 机制 | 先固定的语义 | 可比较的切分与复用 | 不应忽略的成本/边界 |
|---|---|---|---|
| Add/Mul 等广播 | 右对齐补维、各轴真实 stride、输出布局 | 连续内层分块、广播侧参数驻留、多行共用短参数 | 展开索引成本、重复读取、对齐、驻留与 tile 争抢 UB |
| Permute/Transpose | 轴映射、真实输入/输出 stride | 将交换维放入局部二维块、沿连续轴搬运 | UB 重排指令和暂存；经 GM 中转会增加流量；不能把非连续块当一次连续搬运 |
| SwiGLU/门控 | 一张量沿属性轴对半分、两路输入或其他变体 | 成对取得 a/b；尾轴两半连续时分段载入，非尾轴保持 outer/split/inner 映射 | 两路配对、silu 中间舍入和转换、非尾轴地址成本；切 tile 不能破坏配对 |
| RoPE/旋转 | half 或 interleave、旋转维、系数输入/生成方式、广播布局 | 利用 token/head 独立性；half 半区或 interleave 偶奇重组；复用系数 | 只收到系数时不额外生成三角函数；部分旋转、位置映射和 in-place 另核原规格 |
| DynamicQuant | per-token/per-group 统计域、scale公式、clamp、round、输出打包 | 完整统计后量化；数据驻留一遍读，或分段统计后重读/重算；短域多行合并 | 统计完成依赖、scale输出、量化组边界；不同smooth/group变体不得静默泛化 |

## 配对的地址模型

例如单输入 x 沿 dim 对半分为 a/b 时，用 `outer × split × inner` 表达地址；dim 为尾轴时两半分别连续，非尾轴时配对跨 split 轴但各 inner 段可连续。不能把任意相邻元素当作配对。

half 旋转通常保留前后半区对应；interleave 旋转保留最后维偶奇对应。形状 `[1,64,128]` 若64个 head独立，可以有64个任务；不能仅因 token=1 就判断没有核间并行。实际布局和算子变体必须支持该映射。

## 统计与访存趟数

动态量化的 scale 依赖完整 max/amax 等统计，因此量化计算要等统计完成。输入一次读入并驻留，可以做到“一遍 GM 读、两阶段计算”；这不是在线完成最终量化。输入已丢弃则须把重读计入成本。

量化 per-group 边界属于语义；tiling 的 tile 边界可以切在其内部，但统计合并与打包要恢复完整组，不能把不同组并入同一次统计。参考中的127、clamp值或舍入方式是特定规格的例子，不作所有量化变体的默认。

## 融合后的预算

融合输入、参数常驻、升精度中间、输出与 scratch 共同占用 UB。参数驻留减少重复搬运，却可能缩小行组或 tile；应比较全路径成本。继续读[Norm 融合](norm-fusion.md)、[物理账本](resource-lifetime.md)及[API 边界](api-precision.md)，沿原流程确认精度和实测收益。


## 紧凑布局的配对地址算例

单输入沿dim等分为a/b，逻辑形状是 `[outer,2*split,inner]`；给定o、j、k时：

```text
a_index = (o*(2*split)+j)*inner+k
b_index = (o*(2*split)+split+j)*inner+k
0≤j<split, 0≤k<inner
```

该式限标准紧凑布局，其他stride回到真实映射。dim为尾轴时inner=1，两半可分别连续；非尾轴每个inner片段仍可连续，不应错误地改成相邻偶奇配对。旋转interleave则按其独立原规格处理。

广播代表例：`[2048,4096]×[4096]`，FP16整行参数驻留为8,192 byte；每核加载次数另计，不能将参数常驻写成全局只读一次。
