# 运行期与精度：只展开当前方案涉及的成本

用于多阶段 kernel、host 准备、缓存或数值/API 假设的选型。结论写在已有 DESIGN、评审或性能说明中。

## 运行期开销

| 方案变化 | 比较时一并核算 |
|---|---|
| 拆分统计、合并或后处理 | 启动次数、中间 GM/workspace 读写、同步和必要清零 |
| 参数求解、重排或发布移到 host | 平台查询、参数求解、H2D、分配与发布发生的阶段和次数 |
| 缓存参数或工作区 | device、配置、输入依赖、stream/并发、图捕获及资源生命周期的有效性 |
| 改 tile、加驻留或双缓冲 | 额外循环/转换、容量变化、重读与并行任务变化 |

缓存条目在真实初始化完成后才可供相应消费者使用；变化的输入依赖必须失效，异步消费者使用期间不能释放或改写其资源。没有机制证据时不声称安全复用。

冷启动、eager 稳态、图捕获和重放分别报告；kernel 与 host/端到端时间分清。未知准备开销不能填零，已有有效同条件证据可沿原流程复用。

## 数值与 API 假设

- Cast、in-place/别名、近似数学和归约累加的行为绑定目标 SoC、CANN/编译器版本、dtype、重载与参数。数学恒等不能直接证明同 dtype Cast 是合法拷贝。
- Rsqrt 等近似公式的误差依赖实际计算和舍入路径；资料中的试点误差数字不能作为硬件规格，修正方案按原精度合同验证。
- 一个 dtype 通过不能排除共享上游问题，尤其当容差或舍入不同；未执行的输出比较不得记为通过。
- SDK/源码事实、受控试验观察和待验证假设分别注明依据与适用域。多项同时修改后通过，不足以把根因归给其中一项。

这些内容用于选型和排查；最终沿原全量正确性及同条件性能验收。来源与适用边界见 [SOURCES.md](SOURCES.md)。
