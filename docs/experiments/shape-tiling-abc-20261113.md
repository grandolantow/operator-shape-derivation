# Shape tiling：四算子 A/B/C1 实验结果

结果批次：2026-11-13；流程范围复核：2026-11-14。四算子的 A/B/C1 全量精度、性能结果已完成并冻结，供工作流及知识变更的 PR 评审；本次文档整理没有新增设备实验。完整审查结论及历史证据边界列在后文。

## 对照定义与统计口径

- A：自然生成，不提供本轮增强材料。B：接续获准的 A 产物并使用增强材料。C1：从原需求独立使用增强材料生成。实际交接谱系和后验验收分别记录，不能把后来才合格的 A 倒填为早先 B 的生成输入。
- 三臂使用原算子语义、完整用例、reference、输入构造、RNG 和容差。性能集合采用本实验原合同的全量集合；这不修改本仓普通生成任务默认冻结的性能集合。
- 每例比值为 `A.ASC_us / candidate.ASC_us`。表中倍率是逐例比值的几何平均（GM），大于 1 表示候选更快。总时比为 `sum(A.ASC_us) / sum(candidate.ASC_us)`，与等权 GM 的含义不同。
- 比较直接配对各臂 ASC 时间，不把各自相对 reference 或 TileLang 的倍率相除。原 quick 为单次、跨卡跨时采样，未证明独占和统计稳定性；原工具字段可能含预热或初始化，不称纯内核或端到端收益。

## Shape 选型与结果的联系

**Histc。** 当前 C1 按输入长度、实际 AIV 与 UB 选择分核和输入 tile；每核局部直方图在多核时再合并。桶号向量化后逐桶 Compare/Select/ReduceSum，成本随桶数和输入 tile 数共同增长，更多核也会增加合并工作。B 沿用当前 A 的分块并复用可重复掩码。结果支持当前实现间有差异，仍须按 shape 权衡桶数、并行度和合并代价；避免逐元素 API 并不要求采用逐桶重扫。

**Interpolate。** C1 以输出行段分工，将输入行暂存后对一段输出批量 Gather、计算权重并写回；依据输入宽度、dtype、UB 和 64-lane 对齐选择 tile。相比逐输出的细粒度处理，片内邻域复用与向量运算可显著减少重复操作。大倍率也受 A 的计算粒度和原计时范围影响，不能全部归因于知识注入。相邻行或 tile 间仍可能重搬输入，host 准备未保证完整计入，55.175792× 是本表原字段的描述性比较。

**Scatter。** C1 将几何拆为 outer、输出轴、源轴和 inner，对满足连续/对齐条件的 shape 批量处理输出轴，按真实 UB 预算选择轴块；其余使用通用路径。以唯一输出写者保证冲突和更新顺序，按源顺序批量读取索引和数据、Gather/Compare/Add/Select，从而摊薄细粒度调用和依赖开销。主机窗口限制单次任务规模。B 使用不同的排序/分组及特定小轴分支，也取得观测收益。两条路线仍存在扫描、排序、屏障或窗口成本；现有 PROF 未逐阶段证明每项贡献，不能把 5.889474× 全部归于某个分支。C1 的 case34 仍慢于 A。

**RMSNorm。** 设计围绕独立行数 M、归约长度 D、dtype、对齐和峰值 buffer 选择行分工、分段与数据复用；长行的重读、短行的补齐及归约尾部都影响成本。B 相对 A 的 GM 约低 1.15%，没有观测到整体收益；如此小的单次差异不作因果解释。C1 的 GM 与总和方向相反，须检查长短行分布及实际阶段成本，不能以少数长例主导的总和掩盖多数 shape 退化。

以上机制来自现有设计和源码观察；缺少对应阶段测量时属于解释候选，不是已证实的性能因果。资料可见、生成前实际阅读、设计采用和性能贡献是不同证据；本次补充结果不能补造历史作者的阅读记录。

## 原流程审查结论与证据边界

- Histc、Interpolate、Scatter：冻结当前三臂数值和候选，不因整理 PR 重跑；原审附注、输入逐位及实载历史不可恢复项继续保留。
- Scatter A：独立审查为 `PASS WITH NOTES`，已证评分下界 77/100；4.2/4.4 未证，不能称满分。case20 来源为原解析记录及完整日志行，而非后来补造的 performance JSON。
- RMSNorm A：已有原精度、性能和独立人工签收，不能改称历史 native audit 已通过。B 原机械审计和附注语义验收已有，首次 edit-check 遗漏不补签历史。
- RMSNorm C1：TL 标准性能 156 例、原 8 组/20 轮独审已完成；这不是 A/C1 ASC 的分子或分母。ASC 原 156 例与 312 侧 PROF 已后验独审，但四个原母任务因收尾依赖缺失仍为 `failed`、`gate_evidence=UNVERIFIED`，不能改写为运行时 PASS。
- C1 原4b允许基线 `geomean(ref/TL) ≥ 0.6` 后跳过4c，进入4d产出报告。实际TL标准基线为3.5593124298。原作者已结合算术强度、六代表的条件 Amdahl/roofline、候选可行性和实现/复验代价作出本轮 STOP 决定，并经原同臂独审确认：**本轮事后4d分析语义已闭**。这不是证明硬件到顶，也不否定未来在不同目标下继续优化。
- 恢复后的 CPU 取证已核齐 C1 全部 156 例的 Pipe、Memory、Arithmetic 原表，原先 80/81 两例只是索引格式不同。按实际 kernel 路由分为 direct 6、resident 122、streamed 4、merged 24 例；分组统计已由原审独立复算一致。case42 原 PMU、工具公式与数据库核对已获独立审查；现有追踪可关联20个迭代、kernel和host launch，未给出核内阶段边界。分析使用合理估计并保留限制：不将重叠比例当互斥阶段，不将未知计数粒度当实际HBM字节，不将理想逻辑流量当物理流量下界。
- 短行scalar调度与streamed分块是已识别方向；假定可消除对应份额的10%–25%时，四代表例的条件加速约1.048–1.150×，实际也可能为零或负值。这些不是实测或保证收益。原审确认，在已达本轮目标、没有已审可直接应用的净收益改动、仍需变更审查/编译/精度和原性能回归的条件下，可以停止本轮实施；不能把先实证新候选的收益作为原文没有的统一收尾前置。精确官方峰值、全部事件物理单位或逐例硬件极限不再作为新增检查。
- 历史精度环境机械 audit 已通过；当前 guard 环境的 current_pass 不成立，部分原临时路径不可读。这些是未来重入前置，不反向否定已独立审定的历史数值，也不自动要求重跑。不得用重建材料补造历史状态。本轮没有查询或使用 NPU；进一步实现或诊断不属于本 PR 的离线文档整理。

原同臂独审按既有清单确认：4d关闭后，未发现另一项尚未满足的原流程语义条款，**RMSNorm C1本轮事后独立语义审查完成**。原运行状态和历史复现限制是已披露的边界，不列作新增语义待办。

因此本 PR 可展示四算子全部数值结果及C1已审的工程停止判断。事后独立审阅不会改写原生运行回执为PASS，也不据此宣称12组无附注原生终验全通过。Cumsum保持用户暂停，不在本页四算子范围内。
